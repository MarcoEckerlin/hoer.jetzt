Musikbot für Discord

Wartungsmodus aktiv

Musik auf deinem Server.
Ohne Werbung, ohne Setup-Abend.

Einladen, /play tippen, fertig. hoer.jetzt spielt Songs, Playlists und Webradio in deinen Sprachkanal — in voller Qualität und ohne Unterbrechung durch Werbung. Wer lieber klickt statt tippt, steuert alles über die Weboberfläche.

Mit Discord anmelden Bot hinzufügen Der Discord-Login ist noch nicht fertig eingerichtet. Client-ID, Secret und Redirect-URI stehen im Adminbereich.

Alles, was klingt

Einzelne Titel, ganze Playlists, Livestreams und Webradio. Warteschlange, Wiederholung, Lautstärke und Bassanhebung sind zwei Klicks entfernt — oder ein Slash-Command.

Läuft weiter

Updates unterbrechen die Wiedergabe nicht: Warteschlange und Abspielposition überleben einen Neustart. Fällt ein Audioserver aus, zieht deine Runde auf einen anderen um — meist hörst du davon nichts.

Pro Server eingestellt

Rechte, Sprachkanäle, Willkommensnachrichten, Reaction-Roles und Protokolle regelst du je Server im Web statt in verstreuten Konfigurationsdateien.

In drei Schritten

Vom Einladen bis zum ersten Song

1. Bot auf den Server holen.
2. In einen Sprachkanal gehen.
3. /play und den Titel, eine Playlist oder einen Radiosender nennen.

Im Chat

/play, /skip, /queue, /radio — die Befehle stehen direkt in Discord zur Auswahl, ohne Handbuch.

Im Web

Anmelden mit Discord, Server auswählen, steuern. Es erscheinen nur die Server, auf denen du selbst etwas zu sagen hast.

Cookie-Hinweis

Diese Website nutzt nur technisch notwendige Session-Cookies, damit Discord-Login, geschützte Bereiche und längere Sitzungen funktionieren.
